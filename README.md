# JavaScript Exam Cheat Sheet

11 beginner-friendly JavaScript practical programs using complete HTML + JavaScript.

## Programs
1. Area of triangle, rectangle, and circle
2. Multiplication table
3. String operations: reverse, replace, palindrome
4. Compare two strings using different methods
5. Countdown timer
6. Array operations: remove, search, empty
7. Append an object to an array and check `Array.isArray()`
8. Set operations: union, intersection, difference, symmetric difference
9. Home page with `onmouseover` and `onfocus` events
10. Student information form with validation
11. Calculator with number and operation buttons

## How to run
1. Download or extract this repository.
2. Open any `.html` file in a web browser.
3. Enter values when prompted or in the form/calculator fields.

## Exam-friendly notes
- Programs use basic HTML and JavaScript; no CSS or external libraries are required.
- Input values are displayed with their results wherever applicable.
- Program 8 treats comma-separated set entries as strings.
- Program 10 performs basic client-side validation for name, mobile number, and email.
- Program 11 uses `eval()` only as a simple classroom demonstration for arithmetic expressions. Do not use `eval()` with untrusted input in real applications.
